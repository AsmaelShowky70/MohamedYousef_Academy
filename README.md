# منصة الأستاذ محمد يوسف التعليمية 🎓
### النسخة الرسمية المتوافقة 100% مع هوستينجر (Hostinger Production Release)

منصة تعليمية متكاملة لتدريس اللغة العربية لطلاب الثانوية العامة والأزهرية، مصممة بأحدث معايير الأداء والسرعة، ومبنية بـ **PHP & MySQL** بدون أي استهلاك زائد للموارد، ومتوافقة تماماً مع سيرفرات الاستضافة المشتركة والسحابية (Hostinger / cPanel / LiteSpeed).

---

## 🌟 أبرز مميزات المنصة:
1. **نظام صلاحيات متعدد المستويات (SuperAdmin & Sub-Admins)**:
   - المالك الرئيسي للمنصة (**أ. محمد يوسف**) يمتلك صلاحيات مطلقة وهو الوحيد المخول بإضافة وتعديل وحذف المشرفين وتحديد صلاحياتهم بدقة من قسم **إدارة المشرفين**.
   - المشرفون المساعدون يحصلون على صلاحيات محددة فقط (مثل: درجات الطلاب فقط، أو إدارة الأكواد، أو إدارة المحتوى) دون إمكانية الوصول لأقسام الإدارة الحساسة.
2. **تفعيل مباشر للكورسات والحصص (Direct Enrollment)**:
   - إمكانية تفعيل أي كورس أو حصة منفردة لأي طالب مباشرة من ملفه الشخصي بدون أكواد وبدون تحويل لصفحات فارغة.
3. **حماية مشغل الفيديو ضد التسريب**:
   - مشغل فيديو مؤمن ومحمي بعلامات مائية ديناميكية وتشفير الروابط لمنع التحميل أو تصوير الشاشة.
4. **نظام الربط بالأجهزة (Single/Multi Device Binding)**:
   - قفل حساب الطالب على أجهزته المعتمدة لمنع مشاركة الحسابات بين الطلاب.
5. **نظام امتحانات تفاعلية وبنك أسئلة**:
   - تصحيح فوري للامتحانات وحساب الدرجات وربط الحضور بالباركود.
6. **أداء فائق واستقرار عالي (High Concurrency)**:
   - مهيأ بـ Gzip Compression والتخزين المؤقت للملفات الثابتة عبر `.htaccess` لتحمل آلاف الطلاب دون تهنيج السيرفر.

## 🚀 خطوات الرفع والتشغيل على هوستينجر (Hostinger):

### 1. إنشاء قاعدة البيانات:
1. ادخل إلى لوحة تحكم هوستينجر (**hPanel**) -> **Databases** -> **MySQL Databases**.
2. أنشئ قاعدة بيانات جديدة باسم مناسب، وحدد اسم المستخدم وكلمة المرور.
3. افتح **phpMyAdmin**، واضغط على **Import**.
4. اختر ملف قاعدة البيانات النظيفة الجاهزة:
   ```
   database/schema_and_data.sql
   ```
   واضغط **Go** ليتم استيراد كافة الجداول وحساب المالك فوراً.

### 2. إعداد الاتصال بقاعدة البيانات:
- انسخ الملف `config/db_config.sample.php` باسم `config/db_config.php`، وضع بيانات القاعدة الخاصة بك:
  ```php
  define('DB_HOST', 'localhost');
  define('DB_NAME', 'اسم_قاعدة_البيانات');
  define('DB_USER', 'اسم_المستخدم');
  define('DB_PASS', 'كلمة_المرور');
  ```

### 3. رفع ملفات الموقع:
- ارفع ملفات هذا المستودع إلى مجلد `public_html` في هوستينجر (عبر Git Deployment التلقائي من GitHub أو عبر File Manager).
