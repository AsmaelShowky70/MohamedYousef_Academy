2. مميزات الحماية والتأمين المطبقة على فيديوهات اليوتيوب:
------------------------------------------------------------------------
- تم إضافة حصة تأسيسية من اليوتيوب في كورس "الصرف (للقسم العلمي)" / الدرس الأول.
- المشغل محمي بالكامل بتقنيات احترافية:
  1. تشفير وحجب رابط الـ YouTube من كود الصفحة (View Source): لا يظهر رابط الفيديو 
     أو الـ Video ID إطلاقاً في السورس كود الأصلي للـ HTML، ويتم فك تشفيره داخلياً في الذاكرة.
  2. دروع حماية ضد الضغط (Click Shields): تم وضع دروع شفافة تمنع الطالب من الضغط 
     على عنوان الفيديو أو شعار اليوتيوب أو مشاركة الرابط لفتحه خارج المنصة.
  3. علامة مائية متحركة متغيرة (Dynamic Floating Watermark): يظهر على الفيديو 
     اسم الطالب + رقم هاتفه + كود الحضور ID، وتتحرك عشوائياً كل 4 ثوانٍ مع شفافية متغيرة، 
     مما يجعل تصوير الشاشة بكاميرا خارجية أو برامج التسجيل مستحيلاً دون كشف هوية الطالب.
  4. فخاخ كشف أدوات المطور (Anti-Inspect & Anti-DevTools): إغلاق F12 واختصارات التفتيش، 
     وحماية MutationObserver التي تحجب وتشوش الفيديو فوراً إذا حاول أي شخص إخفاء العلامة المائية.
  5. فخ تصوير الشاشة (PrintScreen Trap): مسح الحافظة وإظهار شاشة حماية حمراء عند محاولة التقاط لقطة شاشة.

3. خطوات الرفع على استضافة InfinityFree المجانية (للمعاينة قبل هوستينجر):
------------------------------------------------------------------------
الخطوة 1: إنشاء الحساب وقاعدة البيانات في InfinityFree:
1. ادخل على لوحة تحكم InfinityFree (dash.infinityfree.com) ثم افتح الـ Control Panel (vPanel) لحسابك.
2. اذهب إلى قسم: "MySQL Databases".
3. أنشئ قاعدة بيانات جديدة مثلاً: mohamed
   ستجد اسم القاعدة الكامل أصبح بالشكل: if0_XXXXXX_mohamed
4. في نفس الصفحة ستجد بيانات الاتصال الهامة، انسخها:
   - MySQL Host: (مثال: sql100.infinityfree.com أو sql200.epizy.com)
   - MySQL Database Name: (مثال: if0_38000000_mohamed)
   - MySQL Username: (مثال: if0_38000000)
   - MySQL Password: (نفس كلمة مرور حسابك في InfinityFree)

الخطوة 2: استيراد قاعدة البيانات:
1. من لوحة vPanel، اضغط على زر "phpMyAdmin" بجانب القاعدة المنشأة.
2. اضغط على تبويب "Import" (استيراد) من الأعلى.
3. اختر الملف الجاهز والمحدث الموجود في مشروعك:
   database/schema_and_data.sql
4. اضغط زر "Go" بالأسفل، وسيتم استيراد كافة الجداول، الكورسات، الفيديوهات وحساب الأدمن فوراً.

الخطوة 3: تعديل ملف الاتصال (config/db.php):
افتح ملف config/db.php واكتب بيانات السيرفر في الأسطر (14 إلى 18):
$remote_db_host = 'sql100.infinityfree.com'; // اكتب الهوست الخاص بك من vPanel
$remote_db_name = 'if0_38000000_mohamed';    // اكتب اسم القاعدة
$remote_db_user = 'if0_38000000';            // اكتب اسم المستخدم
$remote_db_pass = 'كلمة_المرور_هنا';        // اكتب باسورد حسابك

الخطوة 4: رفع ملفات المنصة:
1. من لوحة التحكم vPanel، افتح "Online File Manager" أو استخدم برنامج FileZilla عبر الـ FTP.
2. افتح مجلد:
   htdocs
   (هام جداً: يجب رفع الملفات داخل مجلد htdocs وليس خارجه!).
3. ارفع كافة ملفات ومجلدات هذا المشروع إلى داخل مجلد htdocs.
4. مبروك! افتح رابط موقعك التجريبي وستعمل المنصة فوراً وتستطيع إعطاء الرابط للعميل للتجربة!

------------------------------------------------------------------------
4. خطوات الرفع على هوستينجر (Hostinger Shared / Premium Hosting):
------------------------------------------------------------------------
1. من لوحة تحكم هوستينجر (hPanel) -> Databases -> أنشئ قاعدة بيانات جديدة.
2. افتح phpMyAdmin الخاص بهوستينجر واستورد:
   database/schema_and_data.sql
3. في ملف config/db.php:
   $remote_db_host = 'localhost';
   $remote_db_name = 'اسم_قاعدة_بيانات_هو comunitate';
   $remote_db_user = 'اسم_المستخدم';
   $remote_db_pass = 'كلمة_المرور';
4. ارفع كافة الملفات إلى مجلد public_html في هوستينجر.

كل شيء تم فحصه وتأمينه واختباره بنجاح 100%!
