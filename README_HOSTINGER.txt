
============================================================
دليل تشغيل ورفع منصة الأستاذ محمد يوسف (النسخة المتوافقة مع هوستينجر)
============================================================

تم بناء هذه النسخة خصيصاً لتعمل بأعلى سرعة وأقل استهلاك للموارد 
على الاستضافة المشتركة (Hostinger Shared / Premium) باستخدام:
- اللغة: PHP 8.2+
- قاعدة البيانات: MySQL / MariaDB (utf8mb4)
- التصميم: نفس التصميم الأصلي بالملي (CSS, Fonts, Images, Animations)
- بدون الحاجة لسيرفر VPS مكلف!

------------------------------------------------------------
1. التشغيل المحلي للتجربة والمعاينة (Local Testing):
------------------------------------------------------------
1. تأكد من تشغيل Apache و MySQL في برنامج XAMPP.
2. اضغط مرتين على ملف:
   start.bat
3. سيتم تشغيل المنصة تلقائياً على الرابط:
   http://localhost:8000
   وسيفتح المتصفح مباشرة.

------------------------------------------------------------
2. بيانات تسجيل الدخول الجاهزة:
------------------------------------------------------------
- الأدمن الرئيسي (أ. محمد يوسف طه):
  الهاتف: 01001893770
  كلمة المرور: mido*236

- طالب تجريبي مفعل:
  الهاتف: 01010937336
  كلمة المرور: 12345678

------------------------------------------------------------
3. طريقة الرفع على هوستينجر (Hostinger Premium Hosting):
------------------------------------------------------------
الخطوة 1: إنشاء قاعدة البيانات في هوستينجر:
- ادخل على لوحة تحكم هوستينجر (hPanel) -> Databases -> Create New Database.
- أنشئ قاعدة بيانات جديدة باسم مثلاً (u123456_mohamed) ومستخدم وكلمة مرور.
- افتح phpMyAdmin الخاص بهوستينجر، واضغط Import.
- اختر الملف الموجود بالمسار:
  database/schema_and_data.sql
  واضغط Go ليتم استيراد كل الجداول وبيانات الـ 30 طالب والكورسات فوراً!

الخطوة 2: تعديل ملف الاتصال:
- افتح ملف config/db.php على السيرفر، وضع بيانات القاعدة الجديدة:
  define('DB_HOST', 'localhost');
  define('DB_NAME', 'اسم_القاعدة_في_هو comunitate');
  define('DB_USER', 'اسم_المستخدم');
  define('DB_PASS', 'كلمة_المرور');

الخطوة 3: رفع الملفات:
- ارفع جميع ملفات هذا المجلد إلى مجلد public_html في هوستينجر.
- افتح موقعك وسيعمل مباشرة مع شهادة الأمان المجانية وبدون أي أخطاء!
